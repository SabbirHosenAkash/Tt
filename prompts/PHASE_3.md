# Phase 3 — Integration, UX and Release Readiness

Do not begin until Phase 2 meets acceptance criteria and the owner explicitly approves.

Integrate approved engine and voice components into the complete PRILINA app without removing features or unexpectedly changing app identity, navigation or data. Verify lifecycle, permissions, chat history, model management, audio focus, foreground/background behavior, error recovery, performance, memory and battery. Apply UX improvements only within approved scope. Review security and dependencies.

Run unit tests, lint, integration tests and CI build. Build debug APK for validation. Build production release only with securely configured signing secrets. Test on physical device if available; otherwise state unverified. Commit source, update handover/progress/build history, publish a real APK release if successful, list limitations and wait for owner confirmation.
